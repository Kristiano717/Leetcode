## 📖 About

This repository documents my daily LeetCode practice as I work through **Striver's A2Z DSA Sheet**, supplemented with selected **NeetCode** problems to strengthen core interview patterns.

The goal is to build a strong foundation in Data Structures & Algorithms through consistent practice and maintain a well-organized reference for future revision.
